# ICH-324-P05

This library is just a pretext to teach nodejs module management. Two simple functionalities `hello` and `shout`


## Pre-requisits

- NodeJS and npm
- A npmjs account


## How to publish my own

- Clone this content
- Login with an access token locally using `npm config set //registry.npmjs.org/:_authToken="<your token>"`
- Publish the module using `npm publish --access public`
